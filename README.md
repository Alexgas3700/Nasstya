# n8n Workflow для публикации контента в VK

Автоматизированный workflow для создания и публикации контента в группе или на странице ВКонтакте с использованием n8n.

## 📋 Описание

Этот workflow позволяет:
- ✅ Автоматически публиковать посты в VK по расписанию
- ✅ Планировать время публикации контента
- ✅ Загружать текст и медиафайлы (изображения)
- ✅ Логировать все публикации в Google Sheets
- ✅ Обрабатывать ошибки публикации

## 🚀 Быстрый старт

### Предварительные требования

1. **n8n** - установленный и запущенный экземпляр n8n
   - Самостоятельный хостинг: [Инструкция по установке](https://docs.n8n.io/hosting/)
   - n8n Cloud: [Регистрация](https://n8n.io/cloud/)

2. **VK Access Token** - токен доступа к VK API
3. **VK Group ID** - ID группы или страницы VK
4. **Google Sheets** (опционально) - для логирования публикаций

### Установка

#### Шаг 1: Получение VK Access Token

1. Перейдите на [VK Developers](https://dev.vk.com/)
2. Создайте Standalone-приложение:
   - Откройте раздел "Мои приложения"
   - Нажмите "Создать приложение"
   - Выберите тип "Standalone-приложение"
   - Заполните название и описание
3. Получите токен доступа:
   - Перейдите в настройки приложения
   - Скопируйте **Access Token** (сервисный ключ доступа)
   - Или используйте OAuth для получения токена с правами:
     - `wall` - публикация записей
     - `photos` - загрузка фотографий
     - `groups` - управление сообществами

**Важно:** Для публикации от имени сообщества нужны права администратора.

#### Получение токена через OAuth (рекомендуется):

```
https://oauth.vk.com/authorize?client_id=ВАШ_CLIENT_ID&display=page&redirect_uri=https://oauth.vk.com/blank.html&scope=wall,photos,groups,offline&response_type=token&v=5.131
```

Замените `ВАШ_CLIENT_ID` на ID вашего приложения. После авторизации токен будет в URL.

#### Шаг 2: Получение VK Group ID

1. Откройте вашу группу/страницу VK
2. ID находится в адресной строке:
   - Для группы: `https://vk.com/club123456789` → ID = `123456789`
   - Для публичной страницы: `https://vk.com/public123456789` → ID = `123456789`
   - Для короткого адреса используйте [VK API метод resolveScreenName](https://dev.vk.com/method/utils.resolveScreenName)

#### Шаг 3: Импорт workflow в n8n

1. Откройте n8n
2. Нажмите на кнопку "Import from File" или "Import from URL"
3. Выберите файл `n8n_workflow.json`
4. Workflow будет импортирован в ваш экземпляр n8n

#### Шаг 4: Настройка переменных окружения

В n8n установите следующие переменные окружения:

**Способ 1: Через UI n8n (Settings → Environments)**
```
VK_ACCESS_TOKEN=ваш_токен_доступа_vk
VK_GROUP_ID=id_вашей_группы
GOOGLE_SHEET_ID=id_google_таблицы (опционально)
```

**Способ 2: Через файл .env (для self-hosted)**
```bash
# Добавьте в файл .env
VK_ACCESS_TOKEN=vk1.a.ваш_токен_здесь
VK_GROUP_ID=123456789
GOOGLE_SHEET_ID=1abc-def_ghi-jkl (опционально)
```

**Способ 3: Через переменные окружения системы**
```bash
export VK_ACCESS_TOKEN="vk1.a.ваш_токен_здесь"
export VK_GROUP_ID="123456789"
export GOOGLE_SHEET_ID="1abc-def_ghi-jkl"
```

#### Шаг 5: Настройка Google Sheets (опционально)

Если вы хотите логировать публикации в Google Sheets:

1. Создайте новую Google таблицу
2. Создайте лист с именем "Logs"
3. В n8n настройте OAuth2 подключение к Google Sheets:
   - Откройте узел "Save Log to Google Sheets"
   - Нажмите "Create New Credential"
   - Следуйте инструкциям для OAuth2 авторизации
4. Скопируйте ID таблицы из URL:
   - `https://docs.google.com/spreadsheets/d/SHEET_ID/edit` → SHEET_ID
5. Установите переменную `GOOGLE_SHEET_ID`

**Альтернатива:** Можно использовать другие методы логирования:
- Webhook
- Database (PostgreSQL, MySQL)
- File System
- Email уведомления

## 📖 Структура Workflow

### Узлы (Nodes)

1. **Schedule Trigger** (Cron)
   - Запускает workflow по расписанию
   - По умолчанию: каждые 2 часа (`0 */2 * * *`)
   - Настройте под свои нужды

2. **Set Variables**
   - Устанавливает переменные для публикации
   - Загружает токены из переменных окружения
   - Определяет текст поста и время публикации

3. **Prepare VK Data** (Code)
   - Подготавливает данные для VK API
   - Формирует параметры запроса
   - Валидирует обязательные поля

4. **Publish to VK** (HTTP Request)
   - Отправляет POST запрос к VK API
   - Использует метод `wall.post`
   - Публикует контент в указанное время

5. **Check Response** (IF)
   - Проверяет успешность публикации
   - Разделяет поток на успех/ошибку

6. **Log Success / Log Error** (Code)
   - Создает запись лога
   - Сохраняет детали публикации

7. **Save Log to Google Sheets** (Google Sheets)
   - Сохраняет логи в таблицу
   - Можно заменить на другое хранилище

8. **Get Upload Server** (HTTP Request) - *отключен по умолчанию*
   - Используется для загрузки изображений
   - Получает URL для upload через `photos.getWallUploadServer`

9. **Manual Trigger** (Set) - *отключен по умолчанию*
   - Альтернативный триггер для ручного запуска

## ⚙️ Настройка контента

### Изменение текста публикации

Откройте узел **Set Variables** и измените значение `post_text`:

```javascript
{
  "name": "post_text",
  "value": "Ваш текст публикации здесь\n\n#хештеги #теги"
}
```

### Настройка времени публикации

В узле **Set Variables** измените `publish_date`:

```javascript
{
  "name": "publish_date",
  "value": "={{ $now.plus({hours: 1}).toUnixInteger() }}"
}
```

Примеры:
- Через 1 час: `$now.plus({hours: 1}).toUnixInteger()`
- Через 30 минут: `$now.plus({minutes: 30}).toUnixInteger()`
- Завтра в 12:00: используйте конкретный timestamp

### Настройка расписания

Откройте узел **Schedule Trigger** и измените Cron выражение:

- Каждый день в 9:00: `0 9 * * *`
- Каждый час: `0 * * * *`
- Каждые 30 минут: `*/30 * * * *`
- По будням в 10:00: `0 10 * * 1-5`

[Генератор Cron выражений](https://crontab.guru/)

## 📸 Добавление изображений к постам

Для публикации постов с изображениями:

### Шаг 1: Включите узел "Get Upload Server"

1. Откройте workflow
2. Найдите узел **Get Upload Server (for images)**
3. Снимите галочку "Disabled"

### Шаг 2: Добавьте узлы для загрузки изображения

После узла "Get Upload Server" добавьте:

1. **HTTP Request** - загрузка файла на upload_url
   ```
   Method: POST
   URL: {{ $json.response.upload_url }}
   Body: multipart-form-data
   File: ваше изображение
   ```

2. **HTTP Request** - сохранение фото
   ```
   Method: POST
   URL: https://api.vk.com/method/photos.saveWallPhoto
   Parameters:
     - group_id: {{ $json.vk_group_id }}
     - photo: {{ $json.photo }}
     - server: {{ $json.server }}
     - hash: {{ $json.hash }}
     - access_token: {{ $json.vk_access_token }}
     - v: {{ $json.api_version }}
   ```

3. Обновите узел **Publish to VK**, добавив параметр:
   ```
   attachments: photo{{ $json.owner_id }}_{{ $json.id }}
   ```

## 🐛 Решение проблем

### Ошибка: "Access to adding post denied"

**Причина:** Недостаточно прав для публикации

**Решение:**
1. Убедитесь, что вы администратор группы
2. Проверьте права токена (должны быть `wall`, `groups`)
3. Получите новый токен с правильными правами

### Ошибка: "Invalid access_token"

**Причина:** Неверный или истекший токен

**Решение:**
1. Проверьте правильность токена в переменных окружения
2. Получите новый токен через VK Developers
3. Убедитесь, что токен не содержит лишних пробелов

### Ошибка: "User authorization failed"

**Причина:** Токен не авторизован для данной группы

**Решение:**
1. Используйте токен сообщества (группы), а не пользовательский
2. Или получите пользовательский токен с правами `offline` и `groups`

### Публикация не появляется в группе

**Причина:** Пост запланирован на будущее время

**Решение:**
1. Проверьте значение `publish_date`
2. Для немедленной публикации установите `publish_date` в `0` или текущий timestamp
3. Проверьте отложенные записи в настройках группы VK

### Workflow не запускается по расписанию

**Причина:** Workflow не активирован

**Решение:**
1. Откройте workflow в n8n
2. Нажмите кнопку "Active" в правом верхнем углу
3. Убедитесь, что workflow показывает статус "Active"

## 🔐 Безопасность

1. **Никогда не публикуйте токены в коде**
   - Используйте переменные окружения
   - Не коммитьте `.env` файлы в git

2. **Ограничьте права токена**
   - Запрашивайте только необходимые права
   - Используйте токены сообщества вместо пользовательских где возможно

3. **Регулярно обновляйте токены**
   - Меняйте токены каждые 3-6 месяцев
   - Используйте токены с ограниченным сроком действия

4. **Защитите доступ к n8n**
   - Используйте сильные пароли
   - Включите 2FA если доступно
   - Ограничьте доступ по IP если возможно
