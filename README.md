# n8n Workflow для публикации контента в VK

Автоматизированный workflow для создания и публикации контента в ВКонтакте с использованием n8n.

## 📋 Описание

Данный workflow предназначен для автоматической публикации контента (текст, изображения, видео) в группу или на стену ВКонтакте по расписанию. Workflow включает в себя:

- ⏰ Планировщик публикаций (Cron)
- 📝 Публикацию текстового контента
- 🖼️ Загрузку и публикацию изображений
- 🎥 Загрузку и публикацию видео
- 📊 Логирование всех операций
- ⚠️ Обработку ошибок

## 🚀 Установка и настройка

### Шаг 1: Установка n8n

Если у вас еще не установлен n8n, выполните одну из следующих команд:

**С помощью npm:**
```bash
npm install n8n -g
```

**С помощью Docker:**
```bash
docker run -it --rm \
  --name n8n \
  -p 5678:5678 \
  -v ~/.n8n:/home/node/.n8n \
  n8nio/n8n
```

### Шаг 2: Получение токена доступа VK

1. Перейдите на страницу создания приложения VK: https://vk.com/apps?act=manage
2. Нажмите "Создать приложение"
3. Выберите тип "Standalone приложение"
4. Заполните название и описание
5. После создания перейдите в "Настройки" → "Ключи доступа"
6. Получите токен доступа с правами:
   - `wall` - для публикации на стене
   - `photos` - для загрузки изображений
   - `video` - для загрузки видео
   - `groups` - для работы с группами (если публикуете от имени группы)

**Для получения токена можно использовать следующий URL:**
```
https://oauth.vk.com/authorize?client_id=ВАШ_CLIENT_ID&display=page&redirect_uri=https://oauth.vk.com/blank.html&scope=wall,photos,video,groups&response_type=token&v=5.131
```

Замените `ВАШ_CLIENT_ID` на ID вашего приложения.

### Шаг 3: Получение ID группы или пользователя

**Для группы:**
- Откройте страницу группы
- ID группы находится в URL: `https://vk.com/club123456` (ID = 123456)
- Для использования в API используйте отрицательное значение: `-123456`

**Для личной страницы:**
- Откройте свою страницу
- ID находится в URL: `https://vk.com/id123456` (ID = 123456)

### Шаг 4: Импорт workflow в n8n

1. Запустите n8n:
   ```bash
   n8n start
   ```

2. Откройте браузер и перейдите по адресу: http://localhost:5678

3. Нажмите на кнопку "Import from File" или "Import from URL"

4. Выберите файл `vk-content-workflow.json` из этого репозитория

5. Workflow будет импортирован со всеми узлами и настройками

### Шаг 5: Настройка credentials в n8n

После импорта workflow необходимо настроить учетные данные:

1. В n8n перейдите в "Credentials" (значок ключа в левом меню)

2. Создайте новые credentials с именем `vk_credentials` и добавьте следующие параметры:
   - `vk_access_token` - токен доступа VK API
   - `vk_owner_id` - ID группы (отрицательное число) или пользователя
   - `vk_group_id` - ID группы (положительное число, без минуса)

3. Сохраните credentials

4. В каждом узле HTTP Request выберите созданные credentials

### Шаг 6: Настройка расписания

По умолчанию workflow запускается каждый день в 9:00 UTC. Чтобы изменить расписание:

1. Откройте узел "Schedule Trigger"
2. Измените cron-выражение в параметре `cronExpression`

**Примеры cron-выражений:**
- `0 9 * * *` - каждый день в 9:00
- `0 12 * * 1-5` - каждый будний день в 12:00
- `0 */4 * * *` - каждые 4 часа
- `0 18 * * 0` - каждое воскресенье в 18:00

## 📝 Использование

### Базовая публикация текста

Workflow автоматически публикует контент по расписанию. Для настройки контента отредактируйте узел "Prepare Post Data":

```javascript
const postData = {
  message: 'Ваш текст публикации',
  attachments: [],
  publish_date: Math.floor(Date.now() / 1000), // Текущее время
  from_group: 1, // 1 - от имени группы, 0 - от имени администратора
  signed: 0 // 1 - подпись администратора, 0 - без подписи
};
```

### Публикация с изображениями

Для публикации изображений добавьте их в массив `attachments`:

```javascript
const postData = {
  message: 'Текст с изображением',
  attachments: [
    {
      type: 'photo',
      url: 'https://example.com/image.jpg',
      description: 'Описание изображения'
    }
  ],
  publish_date: Math.floor(Date.now() / 1000),
  from_group: 1,
  signed: 0
};
```

### Публикация с видео

Для публикации видео добавьте их в массив `attachments`:

```javascript
const postData = {
  message: 'Текст с видео',
  attachments: [
    {
      type: 'video',
      url: 'https://example.com/video.mp4',
      name: 'Название видео',
      description: 'Описание видео'
    }
  ],
  publish_date: Math.floor(Date.now() / 1000),
  from_group: 1,
  signed: 0
};
```

### Отложенная публикация

Для отложенной публикации укажите время в Unix timestamp:

```javascript
// Публикация через 2 часа
const publishDate = Math.floor(Date.now() / 1000) + (2 * 60 * 60);

const postData = {
  message: 'Отложенная публикация',
  attachments: [],
  publish_date: publishDate,
  from_group: 1,
  signed: 0
};
```

## 🔧 Структура workflow

### Узлы workflow:

1. **Schedule Trigger** - Запускает workflow по расписанию (Cron)
2. **Prepare Post Data** - Подготавливает данные для публикации
3. **VK Post Text** - Публикует текстовый контент через VK API
4. **Check Images** - Проверяет наличие изображений для загрузки
5. **VK Get Upload Server** - Получает URL сервера для загрузки изображений
6. **VK Upload Photo** - Загружает изображение на сервер VK
7. **VK Save Photo** - Сохраняет загруженное изображение
8. **Check Videos** - Проверяет наличие видео для загрузки
9. **VK Save Video** - Получает URL для загрузки видео
10. **VK Upload Video** - Загружает видео на сервер VK
11. **Log Publication** - Логирует результаты публикации
12. **Error Handler** - Обрабатывает и логирует ошибки

### Поток данных:

```
Schedule Trigger → Prepare Post Data → [VK Post Text, Check Images, Check Videos]
                                              ↓              ↓            ↓
                                       Log Publication  VK Upload   VK Upload
                                                        Images      Videos
                                                           ↓            ↓
                                                       Log Publication
```

## 📊 Логирование

Workflow автоматически логирует все операции:

### Успешная публикация:
```json
{
  "timestamp": "2026-01-22T10:00:00.000Z",
  "status": "success",
  "post_id": "12345",
  "message": "Публикация успешно выполнена",
  "details": {
    "text_posted": true,
    "images_uploaded": 2,
    "videos_uploaded": 1
  }
}
```

### Ошибка:
```json
{
  "timestamp": "2026-01-22T10:00:00.000Z",
  "status": "error",
  "error_code": "5",
  "error_msg": "User authorization failed: invalid access_token",
  "request_params": []
}
```

Логи можно просмотреть в консоли n8n или настроить отправку в внешнюю систему мониторинга.

## ⚠️ Обработка ошибок

Workflow включает узел "Error Handler", который обрабатывает следующие типы ошибок:

- Ошибки аутентификации (неверный токен)
- Ошибки прав доступа
- Ошибки загрузки медиафайлов
- Ошибки сети и таймауты
- Ошибки валидации данных

При возникновении ошибки workflow:
1. Логирует детали ошибки
2. Продолжает выполнение (не останавливается)
3. Отправляет уведомление (если настроено)

## 🔐 Безопасность

**Важные рекомендации:**

1. **Никогда не храните токены в коде** - используйте credentials n8n
2. **Ограничьте права токена** - запрашивайте только необходимые разрешения
3. **Регулярно обновляйте токены** - меняйте токены доступа каждые 3-6 месяцев
4. **Используйте HTTPS** - для загрузки медиафайлов используйте защищенное соединение
5. **Настройте backup** - регулярно экспортируйте workflow

## 🧪 Тестирование

### Ручной запуск workflow:

1. Откройте workflow в n8n
2. Нажмите кнопку "Execute Workflow" в правом верхнем углу
3. Проверьте результаты выполнения каждого узла
4. Убедитесь, что публикация появилась в VK

5. Проверьте результаты

1. Откройте консоль браузера (F12)
2. Перейдите во вкладку "Console"

## 🐛 Устранение неполадок

### Ошибка: "User authorization failed"
- Проверьте правильность токена доступа
- Убедитесь, что токен не истек
- Проверьте права доступа токена

### Ошибка: "Access denied"
- Убедитесь, что у вас есть права администратора группы
- Проверьте, что ID группы указан правильно (с минусом для owner_id)

### Ошибка: "Invalid request"
- Проверьте формат данных в узле "Prepare Post Data"
- Убедитесь, что все обязательные параметры указаны

### Изображения не загружаются
- Проверьте, что URL изображений доступны
- Убедитесь, что изображения соответствуют требованиям VK (формат, размер)
- Проверьте права доступа к photos в токене

### Видео не загружаются
- Проверьте размер видео (максимум 2 ГБ)
- Убедитесь, что формат видео поддерживается VK
- Проверьте права доступа к video в токене
