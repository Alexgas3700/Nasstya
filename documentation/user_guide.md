## Введение

Система рассылок на базе n8n — это автоматизированное решение для управления email-кампаниями. Система позволяет:

- ✉️ Отправлять массовые рассылки с персонализацией
- 📋 Управлять списками получателей
- 🎨 Использовать красивые HTML-шаблоны
- ⏰ Планировать отправку на определенное время
- 📊 Отслеживать статус доставки
- 🔄 Автоматически обрабатывать ошибки и повторные попытки

## Установка и настройка

### Требования

- **n8n** версии 1.0.0 или выше
- **Node.js** версии 18.x или выше
- Доступ к почтовому сервису (SMTP, SendGrid, Mailgun или Amazon SES)

### Установка n8n

#### Вариант 1: Через npm

```bash
npm install -g n8n
n8n start
```

#### Вариант 2: Через Docker

```bash
docker run -it --rm \
  --name n8n \
  -p 5678:5678 \
  -v ~/.n8n:/home/node/.n8n \
  n8nio/n8n
```

#### Вариант 3: Через Docker Compose

```yaml
version: '3.8'
services:
  n8n:
    image: n8nio/n8n
    ports:
      - "5678:5678"
    volumes:
      - ~/.n8n:/home/node/.n8n
      - ./workflows:/workflows
      - ./templates:/templates
    environment:
      - N8N_BASIC_AUTH_ACTIVE=true
      - N8N_BASIC_AUTH_USER=admin
      - N8N_BASIC_AUTH_PASSWORD=your-password
```

### Первоначальная настройка

1. Откройте n8n в браузере: `http://localhost:5678`
2. Создайте учетную запись администратора
3. Импортируйте workflow из файла `workflows/email_campaign.json`

## Настройка почтового сервиса

### Вариант 1: SMTP (Универсальный)

#### Шаг 1: Настройка credentials в n8n

1. Откройте n8n → Settings → Credentials
2. Нажмите "Add Credential"
3. Выберите "SMTP"
4. Заполните данные:

```
Host: smtp.gmail.com (для Gmail)
Port: 587
User: your-email@gmail.com
Password: your-app-password
Secure: false
```

#### Популярные SMTP-серверы:

**Gmail:**
- Host: `smtp.gmail.com`
- Port: `587` (TLS) или `465` (SSL)
- Требуется: App Password (не обычный пароль)

**Yandex:**
- Host: `smtp.yandex.ru`
- Port: `587`

**Mail.ru:**
- Host: `smtp.mail.ru`
- Port: `587`

**Outlook/Office365:**
- Host: `smtp.office365.com`
- Port: `587`

### Вариант 2: SendGrid

#### Преимущества:
- До 100 писем/день бесплатно
- Высокая доставляемость
- Детальная аналитика

#### Настройка:

1. Зарегистрируйтесь на [SendGrid](https://sendgrid.com)
2. Создайте API Key в Settings → API Keys
3. В n8n добавьте SendGrid credentials:
   - API Key: `ваш_api_ключ`

### Вариант 3: Mailgun

#### Настройка:

1. Зарегистрируйтесь на [Mailgun](https://mailgun.com)
2. Получите API Key и Domain
3. Добавьте credentials в n8n

### Вариант 4: Amazon SES

#### Настройка:

1. Настройте AWS SES в консоли AWS
2. Верифицируйте домен или email
3. Получите Access Key ID и Secret Access Key
4. Добавьте credentials в n8n

## Управление списками рассылки

### Формат CSV-файла

Создайте CSV-файл со следующими колонками:

```csv
email,firstName,lastName,customField1,customField2,subscriptionDate,tags
john@example.com,John,Doe,Premium,Active,2026-01-15,customer;vip
jane@example.com,Jane,Smith,Standard,Active,2026-01-18,customer
```

#### Обязательные поля:
- `email` — адрес электронной почты
- `firstName` — имя получателя
- `lastName` — фамилия получателя

#### Опциональные поля:
- `customField1`, `customField2` — дополнительные данные
- `subscriptionDate` — дата подписки
- `tags` — теги (разделенные точкой с запятой)

### Добавление списка в workflow

1. Откройте workflow в n8n
2. Найдите узел "Get Mailing List"
3. Настройте путь к CSV-файлу
4. Сохраните изменения

### Валидация списка

Система автоматически проверяет:
- ✅ Корректность email-адресов
- ✅ Наличие дубликатов
- ✅ Обязательные поля

## Работа с шаблонами

### Доступные шаблоны

#### 1. template_example.html
Основной шаблон с современным дизайном и градиентами.

**Переменные:**
- `{{firstName}}` — имя получателя
- `{{lastName}}` — фамилия
- `{{email}}` — email
- `{{customField1}}` — кастомное поле 1
- `{{customField2}}` — кастомное поле 2
- `{{unsubscribeLink}}` — ссылка отписки

#### 2. template_welcome.html
Приветственное письмо для новых пользователей.

#### 3. template_newsletter.html
Шаблон для новостных рассылок.

### Создание собственного шаблона

1. Создайте HTML-файл в папке `templates/`
2. Используйте переменные в формате `{{variableName}}`
3. Добавьте адаптивный дизайн (media queries)
4. Включите ссылку отписки: `{{unsubscribeLink}}`

#### Пример базового шаблона:

```html
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <style>
        body { font-family: Arial, sans-serif; }
        .container { max-width: 600px; margin: 0 auto; }
    </style>
</head>
<body>
    <div class="container">
        <h1>Здравствуйте, {{firstName}}!</h1>
        <p>Ваше сообщение здесь.</p>
        <a href="{{unsubscribeLink}}">Отписаться</a>
    </div>
</body>
</html>
```

### Тестирование шаблона

1. Откройте шаблон в браузере
2. Проверьте отображение на разных устройствах
3. Используйте сервисы типа Litmus или Email on Acid

## Создание и запуск кампаний

### Способ 1: Ручной запуск

1. Откройте workflow в n8n
2. Нажмите "Execute Workflow"
3. Выберите "Manual Trigger"
4. Нажмите "Execute"

### Способ 2: Запуск по расписанию

Workflow автоматически запускается каждый понедельник в 9:00 (настраивается).

### Способ 3: Запуск через Webhook

Отправьте POST-запрос на webhook URL:

```bash
curl -X POST https://your-n8n-instance.com/webhook/email-campaign \
  -H "Content-Type: application/json" \
  -d '{
    "campaign_name": "Summer Sale 2026",
    "template_name": "template_example",
    "sender_email": "marketing@example.com",
    "sender_name": "Marketing Team"
  }'
```

### Параметры кампании

При запуске можно указать:

```json
{
  "campaign_name": "Название кампании",
  "template_name": "template_example",
  "sender_email": "noreply@example.com",
  "sender_name": "Ваша Компания",
  "subject": "Тема письма",
  "mailing_list_path": "/path/to/list.csv"
}
```

## Планирование рассылок

### Настройка Schedule Trigger

1. Откройте workflow
2. Найдите узел "Schedule Trigger"
3. Настройте Cron-выражение

#### Примеры Cron-выражений:

```
0 9 * * 1        # Каждый понедельник в 9:00
0 10 * * 1-5     # Будни в 10:00
0 14 1 * *       # 1-е число месяца в 14:00
0 9,15 * * *     # Каждый день в 9:00 и 15:00
*/30 * * * *     # Каждые 30 минут
```

### Лучшие практики планирования

- 📅 **Будние дни**: Вторник-четверг показывают лучшие результаты
- ⏰ **Время**: 9:00-11:00 и 14:00-16:00 (по местному времени)
- 🚫 **Избегайте**: Понедельник утром, пятница вечером, выходные
- 📊 **Тестируйте**: A/B тестирование времени отправки

## Мониторинг и отслеживание

### Логирование

Система автоматически ведет логи:

#### Успешные отправки
Файл: `/data/logs/success_YYYY-MM-DD.json`

```json
{
  "timestamp": "2026-01-21T09:15:30Z",
  "campaign": "Newsletter January",
  "recipient": "user@example.com",
  "status": "sent",
  "messageId": "abc123"
}
```

#### Ошибки
Файл: `/data/logs/errors_YYYY-MM-DD.json`

```json
{
  "timestamp": "2026-01-21T09:15:35Z",
  "campaign": "Newsletter January",
  "recipient": "invalid@example.com",
  "status": "failed",
  "error": "Invalid recipient address"
}
```

### Просмотр статистики в n8n

1. Откройте workflow
2. Перейдите в "Executions"
3. Выберите нужное выполнение
4. Просмотрите детали каждого узла

### Уведомления администратора

Настройте узел "Send Completion Notification" для получения отчетов:

- ✅ Начало кампании
- ✅ Завершение кампании
- ✅ Количество успешных отправок
- ❌ Количество ошибок

## Устранение неполадок

### Проблема: Письма не отправляются

**Решение:**

1. Проверьте credentials в n8n
2. Убедитесь, что SMTP-сервер доступен
3. Проверьте логи n8n: `~/.n8n/logs/`
4. Тестируйте отправку одного письма

### Проблема: Письма попадают в спам

**Решение:**

1. Настройте SPF, DKIM, DMARC записи для домена
2. Используйте верифицированный домен
3. Избегайте спам-слов в теме и тексте
4. Включите ссылку отписки
5. Прогревайте IP-адрес постепенно

### Проблема: Низкая скорость отправки

**Решение:**

1. Увеличьте `batchSize` в узле "Split In Batches"
2. Уменьшите задержку в "Wait Between Batches"
3. Проверьте лимиты вашего email-провайдера
4. Используйте SendGrid или Amazon SES для больших объемов

### Проблема: Ошибка "Rate limit exceeded"

**Решение:**

1. Уменьшите размер батча
2. Увеличьте задержку между батчами
3. Проверьте лимиты в `configs/email_service_config.json`
4. Рассмотрите апгрейд тарифного плана

### Проблема: Шаблон отображается некорректно

**Решение:**

1. Используйте inline CSS стили
2. Избегайте JavaScript в шаблонах
3. Тестируйте в разных почтовых клиентах
4. Используйте таблицы для layout (старый, но надежный метод)
